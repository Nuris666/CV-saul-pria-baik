# Saul Pria Baik & Partners

Website multi halaman untuk firma hukum premium Saul Pria Baik & Partners. Dibuat dengan HTML, CSS, dan JavaScript vanilla.

## Halaman

- `index.html` - halaman utama
- `about.html` - profil firma
- `services.html` - layanan hukum
- `cases.html` - studi kasus
- `contact.html` - kontak dan form konsultasi

## File utama

- `saul-pria-baik.css` - styling utama website
- `script.js` - smooth scroll, menu mobile, animasi scroll, counter statistik, dan respons form
- `pengacara pria baik.html` - salinan halaman utama lama untuk kompatibilitas lokal

## Cara menjalankan

Buka `index.html` langsung di browser.

## Deploy ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload semua file project ini ke repository.
3. Masuk ke `Settings` -> `Pages`.
4. Pada `Build and deployment`, pilih `Deploy from a branch`.
5. Pilih branch `main` dan folder `/(root)`.
6. Simpan, lalu tunggu URL GitHub Pages aktif.

## Catatan

Website ini tidak membutuhkan build tool, framework, atau dependency tambahan.
